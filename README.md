# RAW RP
Site statique en français. Ouvre index.html pour le tester.

## GitHub Pages
1. Crée un dépôt GitHub public.
2. Dépose tous les fichiers de ce dossier à la racine.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Ouvre l'adresse affichée par GitHub Pages.

## Personnalisation
- config.js : invitations Discord, réseaux et adresse FiveM.
- index.html : textes, règlement à valider, galerie.
- style.css : couleurs et présentation.
- city.svg : illustration originale de remplacement. Remplace-la ou ajoute tes propres captures autorisées.
- script.js : cartes et prologue original.

Aucun backend, compte utilisateur ou compteur de joueurs en direct n'est inclus. Les liens non configurés affichent une notification.
